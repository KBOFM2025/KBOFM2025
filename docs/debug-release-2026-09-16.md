# 디버깅용 배포 · debug-2026.09.16

현재 개발 작업본을 별도 디버그 브랜치에 보존하는 프리릴리스입니다. 안정 버전이 아니며 운영 세이브 대신 테스트용 세이브를 권장합니다.

## 실행과 로그인

1. 릴리스의 `KBOFM2025-debug-2026.09.16-source.zip`을 내려받아 쓰기 가능한 폴더에 완전히 압축 해제합니다.
2. Python 3.11 또는 3.12를 설치하고 PATH 옵션을 활성화합니다.
3. `run_game.bat`을 실행합니다. 최초 패키지 설치에는 인터넷이 필요합니다.
4. 시작 화면에서 `DEBUG 관리자 로그인`을 선택합니다. 최초 실행에서는 본인이 사용할 ID(4자 이상)와 비밀번호(문자·숫자를 포함한 8자 이상)를 등록합니다.
5. 로그인 후 전용 QA 세이브에서 일정·이벤트·연습경기를 테스트합니다. 일반 세이브와 구분됩니다.

인증은 PC의 로컬 저장 DB를 사용하는 접근 확인 기능입니다. 소스 접근자를 차단하는 서버 보안·DRM은 아닙니다. 디버그 로그인 기능을 우회하거나 공용 계정을 넣지 않았습니다.

## 포함한 변경

- 훈련 센터 전체 UI, 코치 담당 배정·수석 코치 위임, 선수별 훈련 평점과 성장 기록.
- 누적 1군·퓨처스 성적에 기반한 잠재력 재평가 및 고정 정책.
- FA/외국인 계약 협상과 투수의 선발·불펜 전환 제안. 실제 배치는 라인업의 선발·불펜 화면에서 저장합니다.
- 디버그 로그인, 이벤트 점검과 반복 가능한 연습경기.

## 알려진 한계

- 전 구단 위임 조건의 11월 30일 검증에서 682명 중 363명의 세부 능력이 상승했습니다. 성장 속도, 높은 훈련 평점 편향, 월말 회복량은 아직 밸런스 조정 대상입니다.
- 연습경기는 모든 세부 능력치를 활용하지 않으며, 일부 공격 보정도 남아 있습니다.
- 해외 전체 경력 또는 입단 정보가 미확인인 선수는 잠재력 확정을 보류합니다.
- 정규시즌 전체 및 11월 필수 이벤트 전체를 끝까지 진행한 완성판 인증이 아닙니다.

## 배포 제외

개인 세이브, 디버그 인증 DB, 로그, 가상환경, 모델 가중치, 임시 백업과 로컬 수집 선수 사진은 제외합니다. 사진이 없는 선수는 기본 표시로 대체됩니다. AI 모델 없이 규칙 기반 모드로 실행할 수 있습니다.

## 버그 제보

릴리스 태그, Windows/Python 버전, 게임 날짜·구단, 재현 순서, 기대 동작과 실제 동작을 함께 적어주세요. 오류 로그 `data/logs/crash.log`를 공유하기 전 사용자 경로 등 개인 정보를 가리고, 로그인 비밀번호나 인증 DB는 업로드하지 마세요.
