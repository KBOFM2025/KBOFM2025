# 선수별 훈련 평점

실제 일일 훈련 시뮬레이션에서 세이브·선수·날짜별로 한 번 기록한다. 과거 세이브의 훈련 내역을 임의로 소급 생성하지 않는다.

- 1.0~10.0, 소수 한 자리. FM식 표시를 사용하는 자체 게임 평가식이며 FM의 비공개 계산식을 재현했다고 주장하지 않는다.
- 기준 6.8에 훈련 전 컨디션·피로·사기, 개인 중점과 세션의 적합성, 담당 코치 지원, 결정론적 선수별 일일 수행 편차를 반영한다.
- 능력치·잠재력·나이·성장량을 평점으로 환산하지 않는다. 잠재 상한에 도달한 베테랑도 좋은 훈련 평점을 받을 수 있다.
- 훈련 강도를 높였다는 이유만으로 가산하지 않는다. 과도한 훈련이 쌓이면 다음 날 피로를 통해 불리하게 작용한다.
- 휴식·회복, 부상 재활, 국가대표 차출, 훈련 없음은 평점 NULL과 사유를 저장한다. 평균에서 제외하며 0점으로 취급하지 않는다.
- 최근 7일은 현재 게임 날짜 포함 7개 달력 날짜. 이전 7일과 평균 차이를 비교한다. 어느 기간에든 평가일이 없으면 추이는 미표시한다.
- 개인 훈련 표: 7일 평균. 선수 선택 패널: 평균, 평가일 수, 이전 주 대비 변화, 최근 3일 기록. 도움말에 평가 제외 및 계산 범위를 표시한다.
- 평점은 수행 피드백이다. 성장 엔진에 추가 보너스로 중복 적용하지 않으며 높은 점수가 능력치 상승을 보장하지 않는다.

저장 테이블: `player_training_ratings`. 동일 날짜 재실행은 최초 기록을 유지한다. 현재 팀에서 쌓은 기록만 해당 팀의 화면에 표시한다.
