# 월간 훈련·성장 모델

## 구현

- 총 훈련 포인트 60점마다 일괄 +1 하던 일일 엔진을 능력별 누적식으로 교체했다.
- 해당 훈련이 선택한 능력만 누적한다. 다른 능력으로 포인트를 옮길 수 없다.
- 성장량은 기존 훈련·코치 능력/업무량 계산값에 연령, 컨디션, 피로, 사기, 경기감각, 재현 가능한 개인별 반응을 반영한다.
- 생일 정보가 있으면 진행 날짜의 만 나이를 계산한다. 없으면 저장된 나이를 사용한다.
- 높은 능력일수록 다음 1점에 필요한 누적량이 늘어난다. 잠재 한계는 전 선수 평가 모델(`player_potential_model.md`)의 저장된 능력별 상한을 사용하며 재접속으로 재추첨하지 않는다.
- 부상 중과 국가대표 차출 상태에서는 구단 성장량을 주지 않는다.
- 32세 이상은 월말에 신체 능력 하나가 하락할 가능성이 있다. 전 능력 동시 감소는 하지 않는다.
- 야수 체력 세션은 컨디션·피로에 반영하며 침착성을 성장시키지 않는다. 투수 체력은 스태미나에만 연결한다.
- 날짜별 처리 기록으로 재실행 중복 성장을 막고, 상승·하락 이력을 훈련 센터의 선수 성장 탭에 표시한다.

## 근거와 한계

[SABR 2023 연구 발표](https://sabr.org/analytics/presentations/2023)의 MLB·NPB·KBO 타자 분석은 지표마다 전성기와 연령 곡선이 다름을 보여준다. 이 방향성을 참고했지만 해당 연구의 추정계수를 구현한 것은 아니다.

성장 배율, 90점 기본 임계값, 잠재 평가 모델, 월말 하락 확률은 게임용 초기 설계다. 실제 선수의 검증된 잠재력이나 의학적 예측을 의미하지 않는다.
경기감각은 현재 저장된 준비도 지표이며 실제 타석·투구 이닝을 대신하는 정확한 출전량 자료가 아니다. 시설 투자, 멘토링, 개인 성격별 훈련 의지는 아직 별도 모델로 구현하지 않았다.

## 재현

`scripts/simulate_training_month.py`는 원본 선수 DB를 임시 사본으로 복사하고 실제 리그 일일 엔진을 2025-11-01부터 11-30까지 30회 실행한다.
KIA는 팀·개인 훈련을 수석 코치에게 위임하고 나머지 구단은 기본 일정을 사용한다. 결과는 `tmp/training-month-report.json`에 저장한다.
이 검증은 훈련과 일일 선수 상태 계산을 실행하는 엔진 검증이며, 필수 FA·드래프트 업무를 모두 해결하는 UI 플레이스루는 아니다.
한 번의 30일 실행 결과만으로 장기 성장 속도가 현실적으로 보정되었다고 판단하지 않는다.
