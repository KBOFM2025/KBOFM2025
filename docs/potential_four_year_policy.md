# 잠재력 수명주기 · 프로 4년차 기준

## 현재 구현

- 프로 입단 시즌을 1년차로 센다. 공식 페이지의 선수 ID·생년월일을 확인한 입단/지명 정보를 우선하고, 없으면 명시적인 입단 연도 또는 국내 선수의 등록된 드래프트 연도를 사용한다. 1군 데뷔나 군복무 팀 입단을 프로 최초 입단으로 바꾸지 않는다.
- 첫 1군 출장 연도를 입단 연도로 바꾸지 않는다. 이 연도로 5년 이상 경력을 입증할 수는 있지만, 1~4년차로 확정할 수는 없다.
- 1~4년차는 누적 1군·퓨처스 성적 자료가 바뀌었을 때 재평가한다. 훈련으로 현재 능력이 올랐다는 이유만으로 잠재 상한이 매일 따라 올라가지 않는다.
- 5년차가 시작되면 4년차까지의 누적 평가를 고정한다. 기존 5년차 이상 선수는 최초 고정 시점까지의 모든 확보된 시즌을 입력으로 삼는다.
- 실제 고정은 입단 연도와 입단 이후 전체 연도·리그 기록 수집을 확인한 뒤 수행한다. `has_record=0`으로 명시한 무출장과 자료 누락은 구분한다.
- 한번 `fixed`로 저장한 잠재력은 성적·나이·이적·모델 버전의 일상적인 변경으로 다시 산정하지 않는다. 현재 능력치의 성장과 하락은 별개다.
- 고정 전 세부 상한 변경 시 이미 쌓은 훈련 진척을 보존한다. 현재 능력을 소급해서 낮추지 않는다.

## 기록 입력

`data/source/kbo_연도_first_team_hitting.csv`, `...pitching.csv`, `...futures_hitting.csv`, `...futures_pitching.csv`를 모든 연도에 대해 검색한다. 2024·2025만 사용하는 제한과 최근 연도 가중치를 제거했다. 리그 간 비교 보정은 유지한다.
완료되지 않은 시즌의 연간 합계는 미래 정보이므로 사용하지 않는다. 현재 오프시즌 게임 범위에 맞춰 11월 1일을 연간 집계 사용 시작일로 두었다. 시즌 중 실시간 성적 기반 재평가는 아직 별도 집계가 필요하다.

## 2026-09-14 보완 수집

- `scripts/collect_potential_career.py`: 실제 DB의 공식 ID 보유 636명을 대상으로 1,272개 통산 페이지 검증. 2025년까지 연도·소속팀·리그별 상세 성적 7,021행 확보. 선수별 페이지 주소도 각 행에 보관한다.
- `data/source/kbo_potential_career_records.csv`: 타석·안타·장타·삼진·볼넷, 상대 타자·이닝 등 과거 상세 기록. 기존 2024·2025 스냅샷과 중복 계산하지 않는다. 안우진의 별도 과거 보충 파일도 같은 시즌이 있으면 중복 제외한다.
- `data/source/kbo_potential_career_coverage.csv`: 공식 입단/지명 원문, 확인된 입단 연도, 생년월일, 리그, 확인 범위, 출처. 원래 DB의 생년월일·드래프트 필드는 임의 수정하지 않는다.
- 표 머리글, 연도별 경기 수 합계와 통산 경기 수, 선수 생년월일을 검증한다. 공식 표의 명시적 ‘데이터가 존재하지 않습니다’만 빈 경력으로 인정한다. HTTP 성공만으로 무출장이라고 간주하지 않는다.
- 2026년 성적은 수집 당시 페이지에 있더라도 2025 게임 평가 자료에서 제외한다. 누락된 시즌을 임의의 0성적으로 생성하지 않고 검증된 통산 페이지의 수집 범위를 사용한다.
- 이미 입증한 기술은 최근 결장으로 사라지지 않도록, 지원되는 세부 능력에 누적 성적 기반 하한을 적용한다. 구속·수비 등 수집한 성적으로 직접 설명할 수 없는 능력을 타격/투구 결과만으로 재작성하지 않는다.

## 남은 범위와 주의점

외국인 및 해외에서 뛴 국내 선수의 KBO 기록은 연결했지만, KBO 통산 페이지로 MLB·마이너·NPB 경력까지 확인했다고 간주하지 않는다. 해외 경력은 `overseas:career`로 명시하고 고정 보류한다. 입단/신원 미확인 선수도 임의 값으로 확정하지 않는다.

과거 연도 비교 기준은 수집 대상 선수들의 같은 연도·같은 리그 기록으로 구성한 표본이다. 은퇴 선수까지 포함한 해당 연도 전체 리그 평균 또는 검증된 미래 예측 모델이라는 의미는 아니다. 현재 잠재력은 게임용 추정치다.

`tmp/player-potential-audit.json`에서 각 선수의 상태, 입력 기록, 세부 능력 상한, 미확인 범위를 확인한다. 소스 DB에는 잠재 프로필만 갱신하고 현재 능력치·급여·소속 등 나머지 필드는 보존 검증한다.

이번 반영 결과: 682명 중 고정 402명, 재평가 236명, 입단 확인 대기 30명, 전체 경력 확인 대기 14명. 공식 ID가 없는 추가 선수는 이름만으로 기존 프로 선수와 연결하지 않았다. 30일 실제 훈련 엔진 검증 결과 상승 33명, 하락 9명, 유지 640명이었다(임시 DB에서 실행).
